# Onvela Codex Plugin

Connect Codex to Onvela through the Onvela MCP server.

## Install

Add this repository as a Codex plugin marketplace:

```bash
codex plugin marketplace add agehret/onvela_codex_plugin
```

Restart Codex, open **Plugins**, select the Onvela marketplace, and install
the Onvela plugin.

## Authentication

Onvela uses OAuth. After installing the plugin, Codex will open an Onvela
sign-in flow the first time it connects to the Onvela MCP server.

Codex receives access through the permissions approved during OAuth. You can
revoke access from your Onvela account settings.
